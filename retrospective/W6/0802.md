# 2026-08-02 회고

## Keep
- 프로젝트에서 사용할 데이터를 Bronze, Silver, Gold 단계로 나누어 관리하는 방법을 고민하였다.
- 단순한 데이터 분석이 아니라 데이터가 지속적으로 들어오고, 문제가 발생했을 때 다시 처리할 수 있는 파이프라인을 만들기 위해 고민하였다.

## Problem
- 데이터를 얼마나 자주 수집하고 정제해야 하는지와 각 작업을 어떤 주기로 실행해야 하는지 결정하는 것이 어려웠다.
- 데이터 품질 검사, 재처리, 집계와 같은 기능을 어느 단계에서 수행해야 하는지 명확하게 구분하기 어려웠다.

## Try
- 데이터의 제공 주기와 실제 활용 시점을 기준으로 파이프라인의 실행 주기를 결정하겠다.
- 각 데이터 계층의 역할을 명확히 정의하고 원본 보존, 정제, 집계 작업이 서로 섞이지 않도록 설계하겠다.
