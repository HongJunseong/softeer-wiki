# 2026-08-03 회고

## Keep
- Apache Airflow를 활용하여 서울 공공자전거 API 데이터를 수집하고 처리하는 ETL 파이프라인을 구현하였다.
- 동일한 작업을 다시 실행해도 결과가 달라지지 않도록 멱등성을 고려하며 ETL 파이프라인을 설계하였다.
- 프로젝트에서도 데이터 수집부터 정제, 집계까지의 흐름을 구체화하며 파이프라인 구조를 고민하였다.

## Problem
- 단순히 ETL이 정상적으로 실행되는 것과 재시도나 재실행에도 안전한 파이프라인을 만드는 것은 다른 문제라는 것을 느꼈다.
- 프로젝트 아키텍처에서도 데이터 수집 주기와 품질 검사, 재처리 시점을 함께 고려해야 해 설계가 복잡해졌다.

## Try
- 파이프라인을 구현할 때 정상 실행뿐만 아니라 실패, 재시도, 중복 실행 상황까지 고려하여 설계하겠다.
- 데이터의 수집 시점과 처리 대상 시점을 구분하고, 과거 데이터를 다시 처리할 수 있는 구조를 만드는 연습을 하겠다.
