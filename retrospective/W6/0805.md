# 2026-08-05 회고

## Keep
- Airflow ETL 과제를 진행하며 API의 페이지네이션을 처리하고 여러 날짜의 데이터를 하나의 DAG에서 처리하였다.
- 수집한 데이터를 정제하고 대여소 단위로 집계하여 MySQL에 적재하는 전체 ETL 과정을 구현하였다.
- API 호출 과정에서 발생한 오류를 확인하며 외부 API를 사용하는 데이터 파이프라인에서 예외 처리가 중요하다는 점을 경험하였다.

## Problem
- API 호출량 제한과 같은 외부 시스템의 제약으로 인해 정상적인 코드도 실행 중 실패할 수 있다는 점을 경험하였다.
- 데이터 수집, 변환, 적재를 구현하는 것뿐만 아니라 실패한 작업을 안전하게 다시 실행하고 중복 적재를 방지하는 부분까지 고려해야 했다.

## Try
- 외부 API를 사용하는 파이프라인에서는 호출 제한과 오류 코드를 확인하고 Retry와 예외 처리 전략을 함께 설계하겠다.
- ETL 작업을 구현할 때 결과만 확인하지 않고 동일한 작업을 여러 번 실행하여 멱등성이 실제로 보장되는지도 검증하겠다.
