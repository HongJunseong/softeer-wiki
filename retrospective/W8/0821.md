# 2026-08-21 회고

## Keep
- 런타임에 한쪽 조인 결과가 충분히 작아지면 AQE가 Sort Merge Join을 Broadcast Hash Join으로 전환할 수 있음을 확인하였다.
- Local Shuffle Reader가 기존 Shuffle 데이터를 가능한 한 로컬에서 읽어 네트워크 전송을 줄이는 역할을 이해하였다.

## Problem
- 최종 계획에서 조인 방식이 바뀐 결과만 보고, 앞선 필터와 집계로 데이터 크기가 얼마나 감소했는지는 놓치기 쉬웠다.
- AQE를 활성화하면 모든 쿼리가 자동으로 빨라질 것이라 기대했지만 짧은 작업에서는 통계 수집과 계획 변경의 이점이 작았다.

## Try
- 조인 전환 여부를 확인할 때 각 Query Stage의 실제 행 수와 바이트 크기를 함께 추적하겠다.
- 대표 쿼리별 기준 성능을 만든 뒤 AQE 적용 전후를 비교하여 효과가 있는 작업과 없는 작업을 구분하겠다.
