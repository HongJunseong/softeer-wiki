## Keep

- 데이터 엔지니어링 프로젝트에서 API 서버, 모델, 스토리지의 역할을 구분하며 전체 시스템 구조를 고민해 보았다.

## Problem
- Lambda가 항상 좋은 선택이라고 생각했지만, 호출 빈도와 실행 시간이 길어질 경우 적합하지 않을 수 있다는 점을 새롭게 알게 되었다.
- 클라우드 서비스마다 비용 구조가 달라 어떤 상황에서 어떤 서비스를 선택해야 하는지 아직 경험이 부족하다고 느꼈다.

## Try
- AWS 주요 서비스의 특징과 비용 구조를 함께 정리하여 상황에 맞는 아키텍처를 선택할 수 있도록 공부하겠다.
- 프로젝트를 설계할 때 운영 비용과 확장성도 함께 고려하는 습관을 기르겠다.
