# 2026-08-12 회고

## Keep
- 필요한 컬럼만 읽는 Column Pruning과 필터 조건을 데이터 소스 가까이 이동시키는 Predicate Pushdown의 효과를 확인하였다.
- Parquet 메타데이터와 파티션 컬럼을 활용하면 전체 파일을 스캔하지 않고도 읽기 범위를 줄일 수 있음을 배웠다.

## Problem
- 쿼리에 필터를 작성했다고 해서 모든 조건이 데이터 소스까지 Pushdown되는 것은 아니며, 함수와 저장 형식에 따라 적용 여부가 달라졌다.
- Partition Pruning과 Predicate Pushdown을 같은 개념으로 생각해 실행 계획의 `PartitionFilters`와 `PushedFilters`를 혼동하였다.

## Try
- `explain("formatted")`에서 ReadSchema, PartitionFilters, PushedFilters를 각각 확인하는 점검 순서를 만들겠다.
- 원본 데이터를 저장할 때 자주 사용하는 조회 조건을 기준으로 파티션 컬럼과 파일 형식을 결정하겠다.
