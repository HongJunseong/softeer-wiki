# Building an Idempotent ETL Pipeline using Airflow

## 1. Airflow 기반 ETL 파이프라인 구축

이번 미션에서는 Apache Airflow를 활용하여 **서울 공공자전거 데이터를 수집하고 처리하는 ETL 파이프라인**을 구축하였다.

- 서울 공공자전거 API를 이용해 지정된 날짜의 데이터를 수집하였다.
- 페이지네이션을 처리하여 전체 데이터를 수집하였다.
- 데이터 수집, 변환, 집계, 적재 과정을 Airflow DAG로 구성하였다.

Airflow의 DAG와 Task를 활용하여 ETL 작업의 실행 순서와 의존성을 관리하는 방법을 익힐 수 있었다.

## 2. 데이터 정제 및 집계

수집한 데이터를 정제하고 대여소 단위로 집계한 뒤 MySQL에 저장하였다.

- 필요한 컬럼을 추출하고 데이터를 정제하였다.
- 여러 날짜의 데이터를 하나의 DAG 실행에서 처리하였다.
- 대여소별 이용 건수, 이동 거리, 이용 시간을 집계하였다.
- 처리된 결과를 MySQL 테이블에 저장하였다.

이를 통해 **Extract → Transform → Load**로 이어지는 데이터 파이프라인의 전체 흐름을 직접 구현할 수 있었다.

## 3. Idempotent Pipeline 구현

동일한 DAG를 여러 번 실행하더라도 결과가 중복되지 않도록 **멱등성(Idempotency)**을 고려하여 파이프라인을 구성하였다.

- 동일한 기간의 데이터를 다시 처리해도 중복 데이터가 생성되지 않도록 하였다.
- Airflow의 재시도 및 재실행 상황을 고려하여 데이터 적재 방식을 설계하였다.
- 실패한 작업을 다시 실행해도 동일한 결과를 얻을 수 있도록 구성하였다.

이번 미션을 통해 Airflow를 활용한 ETL 파이프라인 구축 방법을 익히고, 실제 데이터 파이프라인에서 중요한 **재실행 가능성과 멱등성**의 개념을 이해할 수 있었다.
