# Data Analysis using RDD

## 1. RDD 생성 및 데이터 로드

이번 미션에서는 Apache Spark의 기본 데이터 처리 모델인 **RDD(Resilient Distributed Dataset)** 를 활용하여 데이터를 불러오고 분산 처리하는 과정을 실습하였다.

- 텍스트 파일을 RDD로 생성하여 데이터를 로드했다.
- RDD의 Partition 구조를 확인하며 데이터가 분산 저장되는 방식을 이해했다.

RDD가 Spark의 기본 분산 데이터 구조이며, 여러 노드에서 병렬 처리될 수 있는 단위라는 점을 확인할 수 있었다.

## 2. RDD Transformation과 Action

RDD에서 다양한 Transformation과 Action 연산을 수행하며 Spark의 실행 방식을 확인하였다.

- `map`, `filter`, `flatMap` 등을 이용하여 데이터를 변환했다.
- `reduceByKey`, `groupByKey` 등을 활용해 데이터를 집계하였다.
- `collect`, `count`, `take` 등의 Action을 통해 실제 연산을 수행하였다.

Lazy Evaluation 특성으로 인해 Transformation은 즉시 실행되지 않고, Action이 호출되는 시점에 실행 계획(DAG)에 따라 연산이 수행되는 과정을 이해할 수 있었다.

## 3. 분산 처리 방식 이해

RDD를 활용한 데이터 분석을 수행하며 Spark의 분산 처리 방식을 확인하였다.

- 여러 Transformation을 조합하여 데이터를 분석하였다.
- 실행 결과를 확인하며 DAG와 Stage 단위로 작업이 수행되는 방식을 이해하였다.
- RDD 기반 데이터 처리의 특징과 한계를 확인하였다.

이번 미션을 통해 RDD를 이용한 기본적인 데이터 분석 방법을 익히고, Spark의 Lazy Evaluation과 분산 처리 구조를 이해할 수 있었다.
