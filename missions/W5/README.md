# Week 5

5주차에는 Apache Spark의 핵심 데이터 처리 모델인 **RDD(Resilient Distributed Dataset)** 를 활용하여 분산 데이터 처리의 기본 원리와 동작 방식을 학습했다.

또한 **DataFrame API**를 이용해 데이터를 효율적으로 조회·변환·집계하는 방법을 익히며, Catalyst Optimizer와 같은 Spark의 최적화 기능을 활용한 데이터 처리 방식을 이해하였다. 이를 통해 RDD와 DataFrame의 차이점을 비교하고, 상황에 맞는 데이터 처리 방식을 선택하는 방법을 학습하였다.
