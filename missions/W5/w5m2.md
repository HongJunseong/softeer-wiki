# Data Analysis using DataFrame

## 1. DataFrame 생성 및 데이터 로드

이번 미션에서는 Apache Spark의 **DataFrame API**를 활용하여 데이터를 불러오고 분석하는 과정을 실습하였다.

- CSV 데이터를 DataFrame으로 로드하였다.
- 스키마를 확인하고 컬럼 기반으로 데이터를 조회하였다.

DataFrame이 구조화된 데이터를 효율적으로 처리할 수 있는 Spark의 고수준 API임을 이해할 수 있었다.

## 2. DataFrame을 활용한 데이터 분석

DataFrame API를 이용하여 다양한 데이터 변환과 집계 연산을 수행하였다.

- `select`, `filter`, `withColumn` 등을 활용해 데이터를 조회하고 변환하였다.
- `groupBy`와 집계 함수를 이용해 데이터를 분석하였다.
- `join` 연산을 통해 여러 데이터를 결합하여 분석하였다.

SQL과 유사한 방식으로 데이터를 처리할 수 있으며, 복잡한 분석도 간결하게 작성할 수 있다는 점을 확인하였다.

## 3. Spark 최적화 방식 이해

DataFrame 기반 분석을 수행하며 Spark의 최적화 과정을 확인하였다.

- 실행 계획을 확인하며 Logical Plan과 Physical Plan의 차이를 살펴보았다.
- Catalyst Optimizer가 실행 계획을 최적화하는 과정을 이해하였다.
- RDD보다 DataFrame이 최적화된 실행 계획을 통해 더 효율적으로 데이터를 처리할 수 있음을 확인하였다.

이번 미션을 통해 DataFrame API를 활용한 데이터 분석 방법을 익히고, Spark의 실행 계획과 최적화 과정을 이해하며 RDD와 DataFrame의 차이를 학습할 수 있었다.
